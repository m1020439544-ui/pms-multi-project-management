# 智项目 · 多项目管理系统

运营商行业（BSS/OSS/MSS 域）多项目管理系统，覆盖项目启动 → 实施 → 收尾全生命周期，支持项目管理、前后向资金台账、文档中心、提醒中心、AI 能力配置与全局菜单自定义。

## 技术栈

- 后端：Node.js 24 + Express + 内置 `node:sqlite`（零外部数据库依赖，本地 SQLite 文件存储）
- 前端：原生 JS SPA（Hash 路由）+ 设计系统 CSS，无第三方前端运行时依赖
- 文档：`docx` 生成 AI 模板文档
- 附件：本地目录 `data/uploads`，支持上传/下载

## 快速开始

```bash
cd pms
npm install
npm start
```

启动后访问：http://localhost:3000

## 数据模型

后端实体与《研发交接文档-需求规格说明书》第 3 节一一对应：

- `projects`：项目主数据
- `fund_in` / `fund_out`：前向回款 / 后向支付条款
- `sub_contracts`：后向合同（剩余未签约、已签约未支付自动派生）
- `attachments` / `doc_folders` / `doc_files`：附件与文档目录树
- `reminders` / `remind_rules`：提醒事件与规则
- `ai_models` / `ai_capabilities` / `ai_call_logs`：模型接入、能力开关、调用日志
- `menu_config` / `users` / `sessions`：全局菜单、用户与会话

## 关键业务规则

1. **管理员验证**：项目/菜单/资金/文档的增删改需要管理员会话，服务端强制校验。
2. **金额联动**：回款率 = Σ实收 / 合同额；后向剩余未签约 = 可签约 − 已签约；已签约未支付 = 已签约 − 已支付。
3. **AI 辅助原则**：AI 只做预填与提示，金额入账必须人工确认（界面固定提示）。
4. **提醒触发**：应收/应付日前 7/3/1 天三级；逾期当日红色预警；高风险项目即时进入待办。
5. **文档目录规范**：新项目自动生成 DICT 售中标准目录（01-前向材料 8 子类 / 02-售中项目管理 5 子类 / 03-收尾归档）。
6. **菜单自定义**：菜单配置存服务端，全站导航动态渲染，含子菜单下拉。
7. **用户权限**：支持用户增删改、角色（管理员/只读）与模块级编辑权限（项目/资金/文档/提醒/AI/菜单）配置；服务端强制校验。
8. **项目显示方式**：项目页支持卡片/表格两种显示方式切换，服务端持久化。

## 目录结构

```text
pms/
├─ server/
│  ├─ index.js      # Express 入口、静态资源、上传、全局错误处理
│  ├─ db.js         # SQLite schema + 种子数据 + 加密/密码工具
│  ├─ auth.js       # 登录、会话、角色中间件
│  ├─ routes.js     # REST API
│  └─ ai.js         # 多模型调用适配与本地兜底
├─ public/
│  ├─ index.html
│  ├─ styles.css
│  └─ app.js        # SPA：8 大界面 + Hash 路由
├─ scripts/         # 浏览器自动化验证脚本（可选）
├─ data/            # 运行时生成：SQLite 数据库、上传文件、加密密钥
└─ package.json
```

## AI 接入说明

- 在「AI 配置」中填写模型 Endpoint 与 API Key（服务端 AES-256-GCM 加密存储），并将能力指定到对应模型。
- 未配置或调用失败时，系统自动回退到本地演示结果，保证功能可用。
- 调用日志全量记录时间、能力、模型、耗时与状态。
