# 智项目 · 多项目管理系统 V1.0 操作指导手册

## 1. 系统简介

智项目 · 多项目管理系统（PMS）面向运营商行业（BSS/OSS/MSS 域）系统集成与智能化项目，覆盖项目全生命周期（商机→启动→实施→收尾→售后），内置 PMO 管理、合同管理、文档中心、模板管理、知识库、提醒中心、AI 能力配置与全局菜单/权限管理。

系统采用 B/S 架构：
- 服务端：Node.js 22.5+（内置 SQLite），数据与附件保存在本地，不依赖公有云。
- 客户端：现代浏览器（Chrome / Edge / Firefox / HarmonyOS ArkWeb 等）。

## 2. 运行环境要求

| 使用方式 | 环境 | 要求 |
|---------|------|------|
| 服务端部署 | Windows 10/11（x64 或 **ARM64**） | Node.js 22.5 及以上 |
| 服务端部署 | Linux（x64 / ARM64）、macOS | Node.js 22.5 及以上 |
| 客户端访问 | HarmonyOS 7 PC | 任意现代浏览器，浏览器访问服务器地址即可 |
| 客户端访问 | Windows ARM 11 | Edge / Chrome 浏览器访问服务器地址 |

> HarmonyOS 7 PC 推荐采用“浏览器访问”模式：服务端部署在 Windows/Linux/ARM 电脑上，鸿蒙 PC 用 ArkWeb 浏览器打开 `http://服务器IP:3000`。
> 若 HarmonyOS PC 提供 Linux 容器或开发者环境，也可按 Linux 章节直接在鸿蒙 PC 上运行服务端。

## 3. 安装与启动

### 3.1 通用准备
1. 安装 Node.js 22.5+：
   - Windows x64：`https://nodejs.org/` 下载 Windows x64 MSI。
   - Windows ARM：选择 **Windows ARM64** 版本 MSI（Node 官方提供）。
   - Linux ARM64：下载对应 ARM64 二进制包。
2. 解压交付包 `pms-v1.0.0`。

### 3.2 Windows（x64 / ARM11）
双击或在终端运行：
```bat
install.bat
start.bat
```
手动方式：
```bat
cd /d 解压目录\pms-v1.0.0
npm install
npm start
```
启动后浏览器访问 `http://localhost:3000`。

### 3.3 Linux / macOS / HarmonyOS 开发者环境
```bash
cd 解压目录/pms-v1.0.0
chmod +x install.sh start.sh
./install.sh
./start.sh
```
或手动：
```bash
npm install
npm start
```

### 3.4 局域网 / 多设备访问
1. 查看服务器局域网 IP（Windows：`ipconfig`；Linux：`ip addr`）。
2. 其他设备浏览器访问 `http://<服务器IP>:3000`。
3. 若无法访问，请放行防火墙 3000 端口。

### 3.5 一键启动与后台运行
- **HarmonyOS / Linux / macOS**：
  - 一键启动（自动装依赖 + 后台运行）：`chmod +x 一键启动.sh && ./一键启动.sh`
  - 后台启动：`./start-bg.sh`
  - 停止后台服务：`./stop.sh`
  - 查看状态：`./status.sh`
- **Windows（x64 / ARM11）**：
  - 后台启动（隐藏窗口）：双击 `start-bg.bat`
  - 停止后台服务：双击 `stop.bat`
  - 前台启动：双击 `start.bat`
- 后台运行日志：`data/pms.log`。

### 3.6 图形化启动界面（V1.0.1 新增，无需输入命令）
- **Windows**：双击 `启动界面.bat`，自动打开启动管理界面。
- **HarmonyOS / Linux / macOS**：双击或执行 `启动界面.sh`，自动打开启动管理界面。
- 启动界面提供按钮：
  - 安装依赖 / 启动系统(后台) / 停止系统 / 打开系统 / 刷新日志 / 刷新状态
- 界面实时显示：运行状态、系统端口、启动界面端口、进程 PID、版本、运行环境与运行日志。

### 3.7 HarmonyOS 7 PC 特别说明（V1.0.2）
- 鸿蒙 7 PC 基于 OpenHarmony 内核，**不能直接运行 Node.js/Linux 脚本**，因此交付包中的 `.sh` / `.bat` 在纯鸿蒙环境下无法安装和启动，这属于系统能力限制，而非程序故障。
- **推荐方式（浏览器访问）**：
  1. 在另一台 Windows（x64/ARM）、Linux 或 macOS 电脑上运行服务端（双击 `启动界面.bat` 或执行 `./一键启动.sh`）。
  2. 在鸿蒙 PC 打开交付包内的 **`鸿蒙浏览器访问.html`**，填入服务器「局域网访问」地址（如 `http://192.168.1.10:3000`），点击「检测连接」确认连通后「打开系统」。
  3. 也可直接在 ArkWeb 浏览器地址栏输入 `http://服务器IP:3000`。
- 若鸿蒙 PC 提供 Linux 容器 / 开发者模式且已安装 Node.js 22.5+，才可使用 `启动界面.sh / 一键启动.sh` 本地运行。

## 4. 登录

| 角色 | 用户名 | 密码 | 权限 |
|------|--------|------|------|
| 管理员（PMO） | `pmo` | `pmo2026` | 全部功能与配置 |
| 只读 | `viewer` | `pmo2026` | 查看，不可增删改 |

管理员可在「设置 → 用户与权限配置」中新增用户，并按模块授予编辑权限（项目/资金/合同/文档/提醒/知识库/模板/AI/菜单）。

## 5. 模块操作说明

### 5.1 总览
- 顶部统计卡：在管项目、合同总额、平均回款率、风险项目。
- 组合甘特图：支持按阶段、风险筛选。
- 项目明细表与右侧待办面板。

### 5.2 项目
- 「批量导入项目」：下载 Excel 模板 → 填写 → 上传；重复项目编号自动跳过并输出明细报告。
- 「新建项目」：填写项目编号、集团商机编码、金额、里程碑、前后向合同等扩展字段。
- 卡片 / 表格两种显示方式切换。
- 点击「选为当前项目」进入项目工作区。

### 5.3 项目工作区
- **项目信息**：基本信息、里程碑与归档、售中管控、前后向合同、金额概览。
- **资金明细**：前向回款 / 后向支付台账、后向合同，金额联动自动重算。
- **过程文档**：DICT 标准目录树，上传/在线管理文档。
- **风险记录**：风险项目与质检问题，AI 风险审核。
- **变更记录**：项目变更台账。

### 5.4 项目三阶段流程（售中 12 步时间戳链）
- 12 个节点：前向发起→前向归档→后向发起→后向归档→开工→到货→完工→完工款支付→初验→初验支付→终验→终验支付。
- 每个节点展示必留档案；管理员可「标记完成 / 重置」。
- 「AI 交付质检」：10 条质检规则一键记录通过/不通过，汇入 PMO 质量检查。

### 5.5 合同管理
- 按项目分类选择，进入单项目视图；含全部合同、前向合同、后向合同、付款计划 4 个 Tab。
- **导入合同**：选择项目与“前向/后向模板”，下载模板后上传 xlsx / pdf / docx / txt，自动识别字段、生成合同并 AI 分析重要条款。
- 每份合同可上传附件（合同扫描件、合同清单等），支持在线查看、下载、删除，并保留操作记录。
- 上传合同后自动 AI 分析：付款、工期、质保、违约、保密、知识产权等条款 + 风险评级。

### 5.6 文档中心
- 标准目录：01-前向材料 / 02-售中项目管理 / 03-收尾归档。
- 文件夹树可增删改；「重建标准目录」可一键恢复 DICT 标准结构。
- AI 模板：项目信息表、日报、周报、里程碑报告、验收报告，可生成 DOCX。

### 5.7 模板管理
- 文档 / 项目 / 合同三类模板，含官方售中关键文档模板（售前交底、施工计划、实施方案、开工启动会、到货签收单、验收报告）。
- 支持上传文件、下载、版本号自动 +1。

### 5.8 PMO 管理（管理员）
- 组合总览：在管、百万级、500万+、超期180天、收入欠费、送审待办。
- 一会八表：进度、风险、超期、质量、送审、收入、欠费、变更 8 张台账。
- 里程碑管控：12 节点时间戳链与逾期统计。
- 质量检查、送审进度、变更台账：新增 / 编辑 / 删除。
- 成员与分工。

### 5.9 知识库
- 自定义分类树、文章增删改查、关键词检索。
- 预置：售中交接问题清单（51项）、六必有、三必做管控矩阵、投资内控要求。
- AI 知识库问答。

### 5.10 提醒中心
- 逾期 / 3天 / 7天三级分组；保证金、开票回款、收入欠费、双周管控、超期180天等规则开关。

### 5.11 AI 配置（管理员）
- 3 家模型接入卡（DeepSeek / 通义千问 / 内部私有化），API Key 服务端加密存储。
- 5 大能力独立开关并指定模型；用量统计与调用日志。
- 未配置模型时自动使用本地规则引擎，功能仍可用。

### 5.12 设置（管理员）
- 全局菜单自定义：主/子菜单增删改、排序、显隐、按角色可见。
- 菜单配置导出 / 导入 / 模板下载。
- 用户与权限配置：新增/编辑/删除用户、角色与模块权限。

## 6. 数据与备份

- 数据库文件：`data/pms.db`（SQLite）。
- 附件文件：`data/uploads/`。
- 加密密钥：`data/secret.key`（用于 AI Key 加密，请勿丢失）。

备份：停止服务后，复制整个 `data` 目录即可。
恢复：停止服务，用备份 `data` 目录替换后重启。

## 7. 常见问题

| 问题 | 处理 |
|------|------|
| 端口 3000 被占用 | 启动命令前加环境变量，例如 Windows：`set PORT=3001 && npm start`；Linux：`PORT=3001 npm start` |
| 局域网无法访问 | 检查防火墙放行 3000 端口；确认客户端与服务器同一网络 |
| 忘记管理员密码 | 删除 `data/pms.db` 后重启，系统将重建数据库并恢复演示账号（会清空数据，请先备份） |
| 上传文件失败 | 检查 `data/uploads` 目录是否存在且可写；单个文件上限 50MB |
| HarmonyOS PC 无法直接运行 | 使用“浏览器访问”模式，由 Windows/Linux/ARM 主机提供服务 |
| Windows ARM11 无法启动 | 确认安装的是 Windows ARM64 版 Node.js，而非 x64 版 |
